# Execution Plan Template

## Goal
State the user-visible outcome.

## Context
List the relevant files, source documents, catalogue sheets and existing behavior.

## Constraints
List business, architecture, security, accessibility, SEO and data-quality constraints.

## Work breakdown
- [ ] Discovery and impact analysis
- [ ] Data/model changes
- [ ] UI implementation
- [ ] Server/API implementation
- [ ] Tests and verification
- [ ] Documentation

## Acceptance criteria
Describe observable outcomes, not implementation details.

## Risks and rollback
List risks, migrations, feature flags and rollback steps.

## Verification record
Record commands run and results.
